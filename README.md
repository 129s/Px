# Px

Px is a pixel editor written in [Odin](https://odin-lang.org/) for my personal game dev use. 

## Run

Diectly run this command in project root
```sh
odin run .
```
## Features
- [x] Click to draw
- [x] Q/E decrease/increase brush size
- [x] Move canvas (hand tool)
- [x] Zoom in/out
- [x] Color Picker
- [ ] Palette
- [ ] Layer / Animation
